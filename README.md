# 个人学术主页

这是可直接部署到 GitHub Pages 的静态个人主页。

## 上线

1. 新建名为 `你的GitHub用户名.github.io` 的仓库。
2. 上传本项目全部文件。
3. 在仓库 **Settings → Pages** 中，选择从 `main` 分支的根目录发布。
4. 访问 `https://你的GitHub用户名.github.io`。

## 替换资料

- 在 `index.html` 中搜索并替换“张明”“某某大学”“your-email@university.edu”和论文、专利、学生等示例文本。
- 将个人照片命名为 `profile.jpg`，放入 `assets` 文件夹，并把 `index.html` 中的 `assets/profile.svg` 改为 `assets/profile.jpg`。
- 页面上的“预览我的照片”只供本机预览；要让访客看到照片，请按上一步将图片文件提交到仓库。
